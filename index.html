Start the news server

News, translation and stock prices come through a small server that runs on this computer (browsers can't read other news sites directly). To start it, double-click start.bat in the project folder. It opens this page at http://localhost:8080.

Or run node server.js in the project folder and open http://localhost:8080/#/news.
